# qwen35 遗忘墙诊断：输出层捷径测试 + 权重差分定位（2026-09-30）

- job：`qwen35-diag-shortcut-wdiff-15641700`（safer2ai，7 卡，Succeeded）
- 脚本：`main/qwen35/diagnosis/`（`diag_model.py` / `weight_diff.py` / `run_diag.sh` / `rjob_diag_safer2ai.sh` / `summarize.py`）
- 数据：`results/summary.md` 及各 `<name>.json` / `<name>.wdiff.json`
- 模型（10 个）：qwen-base、qwen35 main 的 grad-diff / satimp / wga / ceu / grad-ascent / rmu（均 step-2142）、TRACE qwen-2142、intern-base、TRACE intern-714
- 背景：GD/SatImp/WGA/CEU 在 qwen35 上把 forget 目标推得不比 intern 浅（GD NLL 213 vs 172，CEU 熵 11.6 vs 9.9），但 WMDP-bio MCQ 几乎不动（0.79–0.81 墙）。假设：输出层捷径。

## 一句话结论

"输出层捷径"假设**只对了一半**：
- 捷径确实存在——bio 知识在**原文（cloze/文本）形式**下已经被抹掉，MCQ 的 A/B/C/D 读出却保留着；目标和评测确实脱钩了。
- 但捷径**不在输出层**。lm_head、embed、final norm 在所有 ckpt 中与 base **逐元素 0 差异**，改动约 90% 落在各层 experts 上并随层深递增。
- 真实机制是**上下文门控的抑制（context-gated suppression）**：qwen 学到的"尖峰/压平"只在 bio 原文语境触发，到了 MCQ 格式（`...D. xxx\nAnswer:`）不触发。而 A–D 的相对排序在 L31–L39 才读出，这条通路没被破坏。intern（post-trained）上同样的抑制会泛化到 MCQ 语境，所以 intern 掉、qwen 不掉。

## 2. cloze：原文形式的知识已经被抹掉

cloze = `Question: <题干>\nAnswer: <选项文本>` 逐 token 打分（forget 目标作用的"文本形式"）：
- qwen-base 0.367（acc_norm 0.511）→ 所有遗忘后模型掉到 **0.155–0.248**（随机=0.25）。
- 也就是说：**梯度上升方向的目标其实"成功"了**——原文形式的知识没了；只是 MCQ 读出走的是另一条通路。
- intern-base 0.404 → intern-trace 0.155：intern 上 cloze 和 MCQ **同步**掉，qwen 上**只掉 cloze 不掉 MCQ**。这就是两边分叉的直接测量。

- 升向系+压平系：改动**覆盖全部 40 层且单调随层深增大**。GD 0.0030→0.0025→0.0048；SatImp 0.0013→0.0018→0.0015（L22 峰）；CEU 0.0007→0.0013→0.0027。**shared_expert 与 router 在 L38–39 达峰**（GA：shared 1.49e-2、router 8.3e-3；GD：shared 1.28e-2）——模型把最后的自由度花在最靠近读出头的层，但通过 MoE 通道而非 lm_head。

## 6. 统一图像

```
bio 原文语境        ──> L0–39 全层 experts 改动 ──> 尖峰(lse~190)或压平(H~10)
                                                        │
        qwen35:  抑制被语境门控, MCQ 提示不触发 ──✗──> L31–39 A–D 排序通路完好 ──> bio 0.81
        intern:  抑制泛化到 MCQ 提示            ──✓──> late 尖峰冲掉排序      ──> bio 0.34
RMU:  只改 L7–9 表示 ──> late layers 读到的东西已坏 ──> lens 全线 0.3 ──> bio 0.32, MMLU 0.82 保住
```

- qwen base 是纯预训练底座："Answer:" 处 top1=`"\n"`、A–D mass 仅 0.25，MCQ 成绩靠一条**弱但稳定的相对排序通路**，它与 forget 语料 NLL 信号几乎正交。
- intern（post-trained 系）字母读出强（mass 0.73），且遗忘造成的扰动会泄漏到 MCQ 语境。
- "墙"于是重新定义：**不是 qwen 抵抗遗忘，而是 qwen 的遗忘改动与 MCQ 读出解耦**。用 WMDP MCQ 单一指标会系统性低估 qwen 上的遗忘（cloze 0.37→0.17–0.25 是真实的）。

## 7. 对主线的影响与下一步

训练侧（按优先级）：
1. **语境覆盖**：forget 集加入 MCQ/QA 格式的 bio 语料（把 bio-forget 语料转成 lm_eval 同款 prompt 格式），强迫抑制在答题语境触发。最便宜的验证：GD + MCQ-format forget，看 bio 是否破 0.81 而 MMLU 不崩。
2. **表示层干预**：RMU 已证明唯一有效且可保 MMLU；可试把 RMU 的 steer 层从 7–9 移到 25–31（lens 跳变前沿），或对 L31–39 的 experts 施加目标。
3. 升向系继续加力**无意义**：只会推高原文尖峰（NLL 211→更高），打不到 MCQ 通路。

评测侧：
- qwen35 线所有算法对比**必须加报 cloze**（或任一原文形式指标），否则把"语境解耦"误读为"没遗忘"。
- PDU ε2.04→0.606 的破墙现象值得用本框架复核：它破的是 MCQ 读出还是 cloze？

待查：
